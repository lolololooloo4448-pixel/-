## 📖 Про проєкт

**Aninmnilove Bot** — Telegram-бот для повністю анонімного спілкування між випадковими користувачами. Жодних імен, юзернеймів чи фото профілю — тільки нік типу `Незнайомець #1234`.

Бот підтримує **два режими** (звичайний та 18+), **систему репутації**, **матчинг за інтересами** та **монетизацію через Telegram Stars**.

Проєкт розроблений як **повноцінний продакшн-бот** з модерацією, антиспамом, рекламою та адмін-панеллю.

---

## ✨ Основні функції

### 💬 Анонімний чат
- **Звичайний режим** — будь-які теми, для всіх
- **Режим 18+** — флірт та відверті розмови
- Повна анонімність — без імен, фото, юзернеймів
- Автоматичне з'єднання випадкових співрозмовників

### 📊 Репутація та рейтинг
- Старт: 50/100 балів
- 👍 +5 за гарну розмову
- 👎 −5 за погану
- Рівні: 💎 Легенда (80+) → 🌟 Дуже хороший (60-79) → ✨ Нормальний (40-59) → 🌱 Новенький (20-39) → 🪨 Підозрілий (0-19)
- Топ-10 користувачів за репутацією

### 🎯 Матчинг за інтересами
8 категорій:
- 🤝 Дружба
- ❤️ Отношения
- 🔥 Пошлості
- 💬 Поговорити
- 🎮 Ігри
- 🎵 Музика
- 🎬 Кіно
- ⚽ Спорт

Бот шукає співрозмовників зі спільними інтересами.

### ⭐️ Монетизація (Telegram Stars)
- **Преміум** — 200 ⭐️/міс (без реклами, пріоритет, знижки, бейдж)
- **Буст топу** — 50-800 ⭐️ (підняття в рейтингу)
- **Кастомний нік** — 150 ⭐️ / 50 ⭐️ для преміум

### 🛡 Безпека та модерація
- Антиспам (8 повідомлень / 5 секунд)
- Фільтр матюків у звичайному чаті
- Скарги адміну з логом повідомлень
- Авто-бан після 3 скарг
- Блокування користувачів
- Підтримка (зв'язок з адміном)

### 📢 Реклама
- Кампанії з таргетингом за режимом та інтересами
- Показ кожні 20 повідомлень
- Статистика показів, кліків та CTR
- Автоматичне завантаження кампаній

### 🎛 Адмін-панель (через команди)
- `/stats` — статистика бота
- `/ban` / `/unban` — бан-система
- `/ads` / `/adadd` / `/adstop` — управління рекламою
- `/adstats` — статистика реклами

```bash

```


## 🏗 Архітектура

### Основні компоненти
- **`UserSession`** — сесія користувача в пам'яті
- **`ChatRoom`** — активна кімната між двома користувачами
- **`sessions`** — словник `user_id → UserSession`
- **`active_rooms`** — словник `user_id → ChatRoom`
- **`search_queue_normal`** / **`search_queue_flirty`** — черги пошуку

### Потік даних
```
Користувач → /start → kb_idle()
                    ↓
              [натискає 💬]
                    ↓
              btn_find_normal()
                    ↓
              start_search(mode=NORMAL)
                    ↓
        [у черзі] або [з'єднання з партнером]
                    ↓
              _create_room()
                    ↓
              Чат активний → relay_message()
                    ↓
              copy_message() → партнеру
```

### Схема БД
```sql
users         # користувачі, репутація, преміум
interests     # обрані інтереси
blocks        # блокування
reports       # скарги
ad_campaigns  # рекламні кампанії
top_boosts    # бусти топу
payments      # історія платежів
```

## ⚠️ Особливості реалізації

### Сумісність з aiogram 3.14 + Python 3.14
У коді враховані наступні обмеження:
- ❌ **НЕ використовується `bot: Bot`** в параметрах хендлерів → `message.bot`
- ❌ **НЕ використовується `|`** у фільтрах
- ❌ **НЕ використовується `UserState`** у декораторах
- ❌ **НЕ використовується `IsAdmin()`** у декораторах → `if is_admin(...): return`
- ✅ **Один фільтр** на декоратор
- ✅ **Перевірка стану** — всередині функції

### Захист від помилок
- Усі функції БД обгорнуті в `try/except`
- Авто-міграція схеми БД при старті
- Стійкість до відсутніх таблиць/колонок
- Логування кожного кроку для діагностики

## 🚀 Деплой на VPS

```bash
# 1. Підключись до сервера
ssh root@your_ip

# 2. Встанови Python
apt update && apt install -y python3 python3-pip python3-venv git

# 3. Клонуй проєкт
cd /opt
git clone https://github.com/yourname/aninmnilove_bot.git
cd aninmnilove_bot

# 4. Встанови залежності
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 5. Створи systemd-сервіс
nano /etc/systemd/system/anonbot.service
```

Вміст сервісу:
```ini
[Unit]
Description=Aninmnilove Bot
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/aninmnilove_bot
ExecStart=/opt/aninmnilove_bot/venv/bin/python /opt/aninmnilove_bot/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Активуй:
```bash
systemctl daemon-reload
systemctl enable anonbot
systemctl start anonbot
systemctl status anonbot
```
